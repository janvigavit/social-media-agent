# 🚀 Social Media Agent

An AI-powered Social Media Agent built using **IBM watsonx Orchestrate**, **Groq API**, **HTML**, **CSS**, and **JavaScript**. It helps users create engaging social media content, marketing strategies, and content plans for multiple platforms.

## ✨ Features

- 🤖 AI Chat Assistant
- ✍️ Caption Generator
- #️⃣ Hashtag Generator
- 💡 Post Ideas Generator
- 📢 Ad Copy Generator
- 📅 Content Calendar
- 📊 Marketing Strategy
- 📈 Trend Analysis
- 🔍 Competitor Analysis
- 💬 Brand Sentiment Analysis

## 🛠️ Tech Stack

- IBM watsonx Orchestrate
- Groq API (Llama 3.3 70B)
- HTML5
- CSS3
- JavaScript

## 🚀 How It Works

1. Select a tool from the dashboard.
2. Enter your requirements.
3. AI processes the request.
4. Get instant, platform-specific content.

## 💡 Example Prompts

- Generate an Instagram caption.
- Suggest trending hashtags.
- Create a 7-day content calendar.
- Write LinkedIn marketing content.
- Analyze my competitors.
